# UI_SPEC — 프로젝트 조건 입력 (F6) + 시각화·리포트 (F3)

웹(Admin) UI 명세. 프론트엔드 스택은 운영 메인(`unitlab-cost-analysis`) React 와 동일하게 두는 것을 가정.

## 1. F6 — 프로젝트/입찰 조건 입력 + 관리

### 1.1 F6.1 입력 폼

필드 구성:

| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 공종 (work_code) | multi-select | ✅ | F9 마스터 |
| 규모 (면적/평형) | number | ✅ | 단위 m² |
| 기간 (시작/종료) | date range | ✅ | |
| 지역 | select | ✅ | 시/도·시군구 |
| 품질 수준 (등급) | select | ✅ | 모듈 등급 STD/PREM 등 |
| 로스율 가정 (기본) | number | ✅ | F6.1.2 |
| 로스율 상한/하한 | number, number | 선택 | F6.1.2 |

#### F6.1.1 필수값 검증

- 폼 제출 시 누락된 필수 필드를 inline 에러로 표시 + 제출 차단.
- 빠진 항목 목록은 토스트로도 노출 (접근성).

#### F6.1.2 로스율 가정

- 단일 값 또는 (기본 + 상한 + 하한) 3-tuple.
- 모델은 상한/하한 시나리오를 함께 계산 (예측 결과의 ci_low/ci_high에 반영 가능).

### 1.2 F6.2 조건 템플릿 저장/불러오기

- F6.2.1 템플릿 이름 + 태그 (`#모듈러`, `#쇼룸` 등).
- 검색/정렬: 이름, 태그, 최근 사용일.
- DB: `project_condition_templates` 테이블 (사용자별).

## 2. F3 — 결과 시각화 + 리포트

### 2.1 F3.1 대시보드 시각화

#### 차트 종류

| 차트 | 데이터 |
|---|---|
| 도넛 | 자재/노무/장비/간접비 비중 |
| 막대 | 공종별 예측 원가 |
| 라인 | 유사 프로젝트 시계열 (단가 추이) |
| 게이지 | 데이터 품질 점수 (F7 데이터 커버리지) |

#### F3.1.1 프로젝트 비교 뷰

- 좌우 분할 또는 다중 컬럼.
- 비교 기준: 총액, 항목별, 로스율, m²당 단가.

### 2.2 F3.2 리포트 다운로드 (PDF/엑셀)

#### F3.2.1 포함 항목 선택

체크리스트 UI:

- [ ] 요약 (총액, KPI)
- [ ] 항목별 분해
- [ ] 공종별 표
- [ ] 근거 (상위 영향 변수, 유사 프로젝트)
- [ ] 데이터 품질 지표
- [ ] 입력 조건 스냅샷

#### F3.2.2 엑셀 표준 템플릿 (M3)

시트 구성:

1. `summary` — 총액, KPI, 입력 조건
2. `breakdown` — 자재/노무/장비/간접비 + 공종별
3. `evidence` — 상위 영향 변수, 유사 프로젝트 목록, 데이터 품질

PDF는 동일 섹션을 페이지 분리.

## 3. 화면 흐름 (M1 시점)

```
[로그인]
  → [데이터 업로드 / 노션 연결]    (F4)
  → [정제 결과 검토]               (F1.3)
  → [프로젝트 조건 입력]           (F6.1)
  → [예측 실행]                    (F2.1)
  → [결과 대시보드 + 근거 보기]    (F3.1, F7.1)
  → [리포트 다운로드]              (F3.2)  ← M2 도달 시점부터
```
