# 데이터 계약서: vendors

업체 표준 DB다.

## 필수 컬럼

| 표준 컬럼 | 설명 |
|---|---|
| vendor_id | 업체 ID |
| vendor_name | 업체명 |

## 권장 컬럼

| 표준 컬럼 | 설명 |
|---|---|
| business_no | 사업자번호 |
| region | 지역 |
| trade_types | 취급 공종/자재 |
| source_system | 원본 시스템 |

## 검증 규칙

- `vendor_id`는 중복되면 안 된다.
- 사업자번호가 있으면 동일 업체 병합 기준으로 사용한다.
- 업체명이 같고 사업자번호가 다르면 별도 검토 대상으로 표시한다.
