# 상세 분석 체크리스트

## 데이터 존재 확인

- [ ] 실제 결제 데이터가 있다.
- [ ] BIM 물량 데이터가 있다.
- [ ] 자재 DB가 있다.
- [ ] 업체 DB가 있다.
- [ ] 계약 또는 증빙 데이터가 있다.

## 결제 데이터 검증

- [ ] 결제 ID가 있다.
- [ ] 프로젝트 ID가 있다.
- [ ] 업체 ID가 있다.
- [ ] 결제일이 있다.
- [ ] 품목명이 있다.
- [ ] 수량이 있다.
- [ ] 단위가 있다.
- [ ] 금액 기준이 명확하다.
- [ ] 공급가액/부가세/총액 구분이 가능하다.
- [ ] 중복 결제 ID가 없다.

## BIM 데이터 검증

- [ ] BIM GUID가 있다.
- [ ] 프로젝트 ID가 있다.
- [ ] 객체 카테고리가 있다.
- [ ] 물량이 있다.
- [ ] 단위가 있다.
- [ ] 자재명 또는 타입명으로 매핑 후보를 만들 수 있다.

## 자재/업체 기준 검증

- [ ] 자재 ID가 있다.
- [ ] 표준 자재명이 있다.
- [ ] 자재 표준 단위가 있다.
- [ ] 업체 ID가 있다.
- [ ] 업체명이 있다.
- [ ] 업체 중복 식별 기준이 있다.

## 계산 가능 조건

- [ ] 결제건이 자재 또는 공종에 확정 매핑된다.
- [ ] 결제 수량과 BIM 물량 단위를 변환할 수 있다.
- [ ] 결제 금액 기준이 하나로 분리된다.
- [ ] 계산 제외 항목의 사유가 기록된다.
- [ ] 계산 결과에서 결제 ID까지 추적된다.
