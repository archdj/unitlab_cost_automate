# 원가 분석 작업 하네스

이 하네스는 실제 보유 데이터를 기준으로 원가 분석 프로그램을 만들기 위한 작업 틀이다.

목표는 다음 세 가지다.

1. 데이터가 계산 가능한 상태인지 검증한다.
2. BIM, 결제, 자재, 업체 데이터를 근거 기반으로 연결한다.
3. 계산 결과에서 실제 결제 근거까지 추적할 수 있게 한다.

## 폴더 구조

```text
harness/
├── data_inbox/        # 원본 또는 익명화 샘플 데이터 배치
├── data_contracts/    # 데이터별 필수 컬럼 정의
├── mapping/           # 자재/업체/공종/단위 매핑 규칙
├── reports/           # 검증 결과와 분석 결과 산출물
├── scripts/           # 검증/프로파일링 스크립트
└── docs/              # 작업 절차와 상세 분석 문서
```

## 사용 순서

1. `data_inbox/`에 샘플 데이터를 넣는다.
2. `data_contracts/`의 필수 컬럼과 실제 컬럼을 비교한다.
3. `mapping/`에 표준 자재, 업체, 단위, 매핑 규칙을 작성한다.
4. `scripts/profile_data.py`로 데이터 구조를 프로파일링한다.
5. `reports/`에 나온 누락 컬럼, 단위 불일치, 매핑 불가 항목을 검토한다.
6. 확정 매핑만 원가 계산 대상으로 사용한다.

## 원칙

- 실제 결제 데이터가 없는 단가는 실적 단가로 인정하지 않는다.
- 매핑 상태가 `confirmed` 또는 `rule_matched`가 아니면 계산에 자동 반영하지 않는다.
- 추천, 예측, 자동 대체 제안은 MVP 범위에서 제외한다.
- 모든 계산 결과는 결제 ID, 프로젝트 ID, 업체 ID, 자재 ID까지 역추적 가능해야 한다.
